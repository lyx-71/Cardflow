# CardFlow - Платформа виртуальных карт

CardFlow это MVP веб-приложение для управления мультивалютными кошельками и выпуска виртуальных карт

**Ссылка на сайт:** [https://cardflow-theta.vercel.app](https://cardflow-theta.vercel.app)

## Стек технологий
- **Frontend:** Next.js (App Router), React, Tailwind CSS, shadcn/ui
- **Backend:** NestJS, Prisma ORM, PostgreSQL
- **Безопасность:** JWT (Bearer Token), Argon2id, AES-256-GCM

## Основной функционал
- Регистрация и аутентификация (JWT)
- Создание кошельков (USD, EUR, RUB)
- Пополнение и вывод средств
- Выпуск виртуальных карт (генерация по алгоритму Луна)
- Шифрование данных карт (AES-256-GCM)
- Оплата популярных сервисов с конвертацией валют
- История транзакций

## Структура проекта
- `/api` — серверная часть (NestJS)
- `/web` — клиентская часть (Next.js)
